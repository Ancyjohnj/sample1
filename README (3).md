# Data Preprocessing Project

## Objective

The objective of this project is to clean and preprocess the dataset by handling missing values, duplicate values, inappropriate values, and outliers.

## Dataset

The dataset contains employee information such as:

- Company
- Age
- Salary
- Place
- Country
- Gender

## Data Preprocessing Steps

1. Explored the dataset and found unique values.
2. Performed statistical analysis.
3. Handled missing values using median and mode.
4. Replaced age value 0 with NaN.
5. Removed duplicate rows.
6. Detected outliers using the IQR method.
7. Filtered data based on age and salary.
8. Created Age vs Salary and Place-wise charts.
9. Applied One-Hot Encoding to categorical variables.
10. Applied StandardScaler for feature scaling.

## Tools Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Conclusion

The dataset was successfully cleaned, analyzed, encoded, and scaled. The processed dataset is ready for further machine learning applications.
